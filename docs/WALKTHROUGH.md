# Final walkthrough

[Watch the final video (1:07)](./walkthrough-rerecorded.mp4).

This shorter edit demonstrates two products per store using physical Android footage, short configuration callouts and no audio. Stationary holds remain brief; no padding is added.

- 0:00-0:26: THREAD & FORM — Everyday Mesh Sneaker, variants, reviews, cart quantities and demo checkout.
- 0:26-0:35: Essential Pullover Hoodie — variant pricing and reviews-unavailable fallback while add to cart remains usable.
- 0:35-0:48: switch to STILL HOME — theme, JPY pricing, reviews disabled, and Mori Dome Table Lamp options.
- 0:48-0:57: Sunday Stoneware Mug — details and single/set-of-two options.
- 0:57-1:07: STILL HOME cart, quantity change and demo checkout.

Times are approximate. Collection grids and existing demo cart rows can contain other products; only these four products receive detail demonstrations.

Store switching selects existing bundled configuration records; it does not edit code live or fetch remote configuration. The reviews fallback is simulated through MockReviewsAdapter. No payment is taken or order placed.
